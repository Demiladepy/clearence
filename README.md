# Clearance

**Travel-Rule-ready private payments on Stellar, built for Lagos and Accra first.**

Payments stay private on-chain: no amount, no sender, no receiver. Each payment carries a
zero-knowledge proof that the sender is KYC'd, within their tier's per-payment and daily limits
under their own country's published rules, and that a compliance record is sealed to the licensed
operator. Only the operator can open that record.

Built on Nethermind's [Stellar Private Payments](https://github.com/NethermindEth/stellar-private-payments)
(Circom + Groth16 on BN254, Poseidon2, Soroban).

## Countries are data, not code

One circuit, one pool, one registry. Nigeria (566) and Ghana (288) are rows in the rule registry,
each published by that country's own operator. Kenya (404) and South Africa (710) are two contract
calls, not a new circuit. Cross-border payments use the sender country's limits, the stricter
Travel Rule threshold of the two, and seal the record to both operators.
See [docs/architecture/multi-jurisdiction.md](docs/architecture/multi-jurisdiction.md).

## Run it

Requires Rust (with `wasm32v1-none`), `circom` 2.2.2, Node 22 + pnpm, `stellar` CLI.

```bash
git clone --recurse-submodules https://github.com/Demiladepy/clearence
cd clearence
pnpm install
make verify
```
